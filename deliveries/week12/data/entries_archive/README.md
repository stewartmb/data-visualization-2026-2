# Entradas horarias de la MTA, 2019–2024

Esta carpeta conserva los perfiles y resultados de las versiones anteriores de Fractal. El [catálogo vigente de Eventos](../spectral/index.json) se prepara con los datos del período de estudio. La vista **Años** usa los agregados OD 2021–2025.

- [Contraste histórico](../../HistoricalContrast.md) y [perfiles de entradas](historical_contrast.json)
- [Adquisición](../../FullPeriodData.md) y [serie mensual](full_period.json)

`atlas.json` conserva la versión original del catálogo con los perfiles de entradas 2021–2024. La aplicación usa `stations.json`, que conserva identificadores, nombres, coordenadas, boroughs y líneas del mismo catálogo. Los archivos de `src/` documentan la última interfaz de Eventos para esa investigación.
